# Contribuindo

Obrigado por considerar contribuir com este projeto.

## Antes de contribuir

- Abra uma issue para discutir mudanças relevantes.
- Descreva o problema, o ambiente testado e o resultado esperado.
- Não envie credenciais, senhas, endereços IP privados ou logs com dados sensíveis.

## Padrões

- Mantenha o foco na automação para CentOS 7.
- Documente comandos, dependências e efeitos no sistema.
- Atualize o README e os arquivos em `docs/` quando necessário.
- Teste alterações em uma máquina virtual descartável.
- Não adicione dependências ou downloads externos sem justificativa.

## Fluxo sugerido

1. Crie um fork ou branch.
2. Faça alterações pequenas e específicas.
3. Atualize a documentação.
4. Teste em um ambiente isolado.
5. Abra um pull request descrevendo a mudança e a validação realizada.
